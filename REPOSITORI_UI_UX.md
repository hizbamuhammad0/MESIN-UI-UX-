# 🎨 Direktori Repositori GitHub untuk Kebutuhan UI/UX Designer

Kumpulan repositori open-source terbaik di GitHub yang dikurasi khusus untuk desainer UI/UX, tim produk, dan *design engineer*. Repositori ini mencakup referensi *Design Systems*, *Design Tokens*, aset visual (ikon & ilustrasi), prinsip psikologi UX, hingga *design-to-code workflow*.

## 🚀 Rekomendasi Alur Penggunaan untuk Proyek Anda
1. **Riset & Benchmark Pola Desain:** Buka [awesome-design-systems](https://github.com/alexpate/awesome-design-systems) dan pelajari pola komponen di Polaris atau Carbon.
2. **Standardisasi Token & Warna:** Terapkan hierarki token menggunakan logika [Amazon Style Dictionary](https://github.com/amzn/style-dictionary).
3. **Penyusunan Desain & Ikon:** Gunakan [Lucide Icons](https://github.com/lucide-icons/lucide) sebagai basis library vektor di Figma.
4. **Validasi Heuristik & UX:** Gunakan prinsip [Laws of UX](https://github.com/jonyablonski/laws-of-ux) sebelum melakukan finalisasi prototipe.
